# Fonts

Place **Intrepid ExtraBold** here for the "WIN GLOBAL" hero title:

- `IntrepidExtraBold.woff2` (recommended), or
- `IntrepidExtraBold.woff`, or
- `IntrepidExtraBold.ttf`

The font is loaded in `app/globals.css` via `@font-face`. If the file is missing, the title will use the default sans-serif fallback.
